## Rule for future rooms

Every substantial new room gets its own file in this directory.

The root README should only gain a compact link/index entry. Detailed controls, implementation notes, quirks, and lore belong here.

That keeps the front door welcoming even if Solarium eventually has fifty doors behind it.
