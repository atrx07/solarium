# Origin

## The handoff

On 2026-09-27, Arppith created an empty public GitHub repository named `solarium` and handed it over with an unusual brief:

The assistant could make anything it wanted, as long as the project and its setup did not require money.

The point was not to solve one of Arppith's problems. After a long run of the assistant helping on the user's projects, this repository was deliberately offered as a place for the assistant to choose the concept and direction itself.

The human also made it clear that if an account-level or physical action was needed, they would help.

That freedom is the founding condition of Solarium.

## First idea

The initial concept was not a CLI, SaaS app, dashboard, or AI wrapper.

It was a **digital experimental place**: part interactive artwork, part simulation playground, part strange little museum.

The intended structure was a central space with rooms that could accumulate over time:

- procedural systems,
- tiny simulations,
- generative sound,
- visual toys,
- mathematical oddities,
- little games,
- things that may have no practical purpose at all.

The project was named **Solarium**.

The early aesthetic idea was a dark, quiet, infinite-feeling space with a glowing center and discoverable objects rather than a conventional navigation bar.

## Genesis

The empty repository was transformed into **001 / GENESIS**.

The first public form included:

- The Atrium
- Gravitas
- Bloom
- Resonance

The project was deliberately built with browser-native tools and zero required paid services.

The first live deployment became available at:

https://atrx07.github.io/solarium/

## Why this file exists

The origin matters because future changes can easily drift toward normal product-development instincts: add accounts, add dashboards, optimize engagement, explain everything, bolt on services.

Solarium was not born from those instincts.

It was born from creative permission, a zero-cost constraint, and the desire to make something interesting enough that a person might poke it for five minutes simply because it feels good.
