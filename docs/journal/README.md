# Solarium Journal Index

Solarium's project memory outgrew one ever-growing file.

The original [`docs/JOURNAL.md`](../JOURNAL.md) remains the immutable historical journal through the **2026-10-02 audio lifecycle audit**. It should not be rewritten merely to append new history.

From 2026-10-04 onward, new entries live in monthly files here:

- [`2026-10.md`](./2026-10.md) — current journal

## Rule

After meaningful work:

1. append the story to the current monthly journal,
2. create a new `YYYY-MM.md` file when the month changes,
3. add that file to this index,
4. keep entries explanatory rather than duplicating raw Git history.

The goal is the same as the original journal: preserve decisions, failures, motivations, and creator notes so a future chat can recover the project's mind, not just its commits.

This split is purely documentation architecture. No historical entry was deleted or rewritten.
